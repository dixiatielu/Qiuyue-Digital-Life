# Treat all group chats as external environments of one digital life

The project aims to create a digital life with an independent persona, long-term memory, and continuing state. The entire system therefore has one Agent with a unified identity, memory, and state; each QQ group is an external environment it perceives and participates in. Separate Agents or chat sessions per group would fragment the subject's experiences and state, so we do not use that structure. The same Agent decides whether to act on events from every group, external actions are executed through tools, and silence is a normal choice.

Unified memory retains people, sources, and social contexts. The same QQ user appearing in different groups remains the same person, and retelling an experience across groups requires consideration of its original sharing scope.
