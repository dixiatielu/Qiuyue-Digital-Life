# Tell the working context each thing once

The working context only grows between compactions, and every later model call reads all of it again. From 2026-10-30 12:00 to 2026-11-02 12:00 a compaction cycle lasted about 78 calls, so anything written into the context was read again some 40 times on average. Over those three days the runtime data appended before calls wrote about 3 million tokens into the context, and much of it was already there. Impressions of 129 people were upserted 1,705 times and 111 recalled memories 880 times, because a delta mirrored what was relevant at the moment: when someone stopped talking their impression was removed, and when they spoke again it came back in full, while the earlier copy was still in the context. Recent events repeated the observations that had just brought them, about 340,000 tokens, and 903 action upserts repeated tool results the context already held.

A delta now says only what the working context does not already show. A memory that runtime data has brought, whether it came to mind or is part of the digital life's development, stays shown until compaction. A delta does not remove it when it no longer comes to mind or repeat it when it does again. It removes it only when the memory no longer holds, because it was retired or revised. What a recalled memory carries is not shortened further. Recent events come only in a snapshot, which stands in for the exchanges compaction removed; new events arrive in observations. An action whose result already came back to the context as a tool result is not repeated. One the context has not seen still comes, such as an action from a thought that was rolled back or one a restart left unknown ([ADR-0008](0008-preserve-unknown-action-outcomes.md)), and so does a later change to an action's outcome. Commitments, plans, pursuits, and the current activity are supplied as before ([ADR-0006](0006-experience-understanding-and-continuing-state.md)).

Revising a memory used to add a `memory_revision` event, which asked the digital life to check the activities and commitments affected and started another model call of its own. Over the same three days there were 232 revisions, mostly of impressions, habits, and practices during memory review, and 148 observations made only of such events, about 22 million prompt tokens. None of the 232 had a memory resting on the old version. A call to `remember` is always followed by another model call in the same thought, so what a revision reaches is now reported in its result: the memories that rested on the old version and left everyday recall with it, and the plans, pursuits, or activity under way that cite it. The digital life reads this at no extra call and decides there whether anything else needs revising. The result no longer repeats the memory it has just written, which is already in its call. A revision the digital life did not make in a thought of its own, such as an operator correction, still comes as a `memory_revision` event, since it would otherwise not learn of it.

Plans and the current activity cite every source of the thought that set them, so a revision may list a plan that cites the old version only because it was in view at the time.
