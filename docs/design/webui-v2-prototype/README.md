# WebUI v2 · 独立设计预览

状态：用户已批准此布局与可调整主题色，正式实现位于 `src/webui/public/`。本目录保留独立设计稿作为评审依据。

这一版用柔和的分区重新组织现有 6 个标签页，并支持调整主题色。所有业务内容为示例，业务操作只留在浏览器内存；没有连接实际接口、凭据或数据库。

直接用浏览器打开 `index.html`，或从仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/design/webui-v2-prototype
```

访问 http://127.0.0.1:4173 。无需安装依赖。

主题色：

- 每个页面右上角都有「主题色」入口。
- 预设：雾蓝、鸢紫、樱粉、墨绿、琥珀、石墨；支持取色器与 3/6 位 HEX 输入。
- 导航、按钮、选中状态、背景与装饰会即时换色；保留成功、警告、错误的语义颜色，并自动调整按钮文字明暗。
- 主题色记录在预览 URL 的 `accent` 参数中，切换标签页或刷新后保留；不写入实际配置。
- 例：`http://127.0.0.1:4173/?accent=536FB5&theme=open`。

页面与子页：

- 状态总览：此刻、实时动态、运行日志。
- 运行配置：分组表单（8 组）、原始 JSON。
- 能力与插件：7 个内置插件、QQ 接口权限、联网设置。
- 人格与成长：核心人格、她的发展、版本记录。
- 系统提示词：模板编辑、最终提示词、内置版本对比、版本记录。
- 模型与连接：主模型、Embedding、画图模型、供应商、凭据。

设计重点：当前活动先于运行指标；长表单按目的分组；依赖与插件开关并排；核心人格与自主发展分开；统一草稿检查和版本对比；运行控制清楚表达等待与中断。

预览的模型 ID、数值、活动、人格、聊天与版本记录均为虚构示例，不代表真实配置或推荐设置。JSON 仅展示布局用片段。事件筛选弹窗、测试结果、修正/删除/保存反馈均演示流程，未接入功能。各类示例参数仍需正式实施时依据后端定义核对。

遵守现有 ADR-0020：独立管理进程、文件保存后重启生效、保留版本与上下文影响说明。遵守 ADR-0012：核心人格由运营者设定，自主发展保留来源与修订记录。

正式实现沿用现有 Preact 组件与后端接口，主题偏好保存在浏览器本地；原型仍然只展示示例数据，不接入运行服务。
